# White Picket Marketing Hub

Agent-facing marketing hub. Each agent opens their private link:
`https://sienna-bit.github.io/whitepicket-hub/?a=<agent-token>`

Admin preview of all agents: `https://sienna-bit.github.io/whitepicket-hub/?admin=1`

- `index.html` — the hub (don't edit by hand)
- `data.json` — agents, listings and graphics; updated automatically
